# 가상 스프린트 (7교시)

약 50분을 스프린트 2주로 생각합니다. 강사가 라운드를 알리면 스탠드업을 합니다.

## 진행

| 순서 | 할 일 |
| --- | --- |
| 라운드 1 | 스탠드업 → 작업 → 돌발 상황 대응 |
| 라운드 2 | 스탠드업 → 작업 → 돌발 상황 대응 |
| 라운드 3 | 스탠드업 → 작업 → 돌발 상황 대응 |
| 마무리 | 릴리스 v1.1 |

## 스탠드업 (라운드당 3분)

한 사람씩 답합니다.

1. 어제 무엇을 했나요?
2. 오늘 무엇을 하나요?
3. 막힌 문제가 있나요?

## 돌발 상황이 오면

1. 무엇이 바뀌는지 Slack에 공유합니다.
2. PO가 범위와 우선순위를 다시 정합니다.
3. Jira 이슈와 담당을 고칩니다.
4. [기록 양식](../project/sprint-log-template.md)에 결정을 남깁니다.

## 끝나기 전 확인

- [ ] Jira 보드가 실제 상태와 같다
- [ ] 끝내지 못한 이슈의 처리를 정했다
- [ ] `CHANGELOG.md` 를 작성했다
- [ ] `main` 에 병합하고 `v1.1` 릴리스를 만들었다
