# 협업 도구 셋업 (2교시)

화면 메뉴 이름은 도구 업데이트로 조금 달라질 수 있습니다. 강사가 안내하는 환경을 따릅니다.

## 도구별 역할

| 도구 | 쓰임 | 넣지 않는 것 |
| --- | --- | --- |
| Jira | 할 일, 담당, 상태 | 긴 회의록 |
| Confluence | 오래 남길 문서 | 매일 바뀌는 작업 상태 |
| Slack | 빠른 소통, 알림 | 결정의 유일한 기록 |
| GitHub | 문서 변경 이력, PR 리뷰 | 작업 진행 상태 |

## Jira

1. **Create project(프로젝트 만들기)** → **Scrum(스크럼)** 템플릿을 고릅니다.
2. 프로젝트 이름은 팀 이름, 키는 짧은 영문으로 정합니다.
3. [백로그](../project/backlog.md)의 항목을 **Backlog(백로그)** 에 이슈로 등록합니다.
4. 이슈에 담당자와 **Story points(스토리 포인트)** 를 넣습니다.

## Confluence

1. 팀 **Space(공간)** 를 만듭니다.
2. 페이지를 만듭니다: 프로젝트 개요, WBS, 일정, 회의록, 회고

## Slack

1. 채널을 나눕니다: `#팀이름-공지`, `#팀이름-작업`
2. 팀 규칙을 고정 메시지로 남깁니다.

## 팀 규칙 정하기 (10분)

- 질문은 어느 채널에 쓰나요?
- PR 리뷰 요청은 어떻게 하고, 얼마 안에 답하나요?
- 결정은 어디에 기록하나요?
- 막히면 몇 분 뒤에 도움을 요청하나요?

## 도구를 쓸 수 없을 때

| 원래 도구 | 대안 |
| --- | --- |
| Jira | GitHub Issues와 Projects |
| Confluence | 팀 저장소의 Markdown 문서 |
| Slack | 강사가 안내하는 팀 소통 채널 |
