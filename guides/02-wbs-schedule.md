# WBS와 일정 (3·4교시)

## 3교시: WBS

1. [프로젝트 소개](../project/brief.md)에서 범위를 확인합니다.
2. 팀이 큰 산출물 3~5개를 정합니다.
3. [WBS 양식](../project/wbs-template.md)으로 작업을 나눕니다.
4. 다른 팀과 바꿔 보고 빠진 일을 찾아 줍니다.

## 4교시: 일정과 스프린트 계획

1. WBS 작업에 기간과 선행 작업을 적습니다.
2. [일정 양식](../project/schedule-template.md)으로 Gantt Chart를 만듭니다.
3. 주경로와 마일스톤을 표시합니다.
4. Jira 백로그의 우선순위를 정합니다.
5. 팀이 해낼 수 있는 양만큼 이슈를 **Sprint(스프린트)** 에 넣고 시작합니다.

## WBS, Gantt, 백로그의 관계

| 도구 | 답하는 질문 |
| --- | --- |
| WBS | 무엇을 해야 하나 |
| Gantt Chart | 언제, 어떤 순서로 하나 |
| 백로그 | 무엇부터 하나 |
| 스프린트 보드 | 지금 어디까지 했나 |
