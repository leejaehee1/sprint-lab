## Try 실행 계획

Try는 Jira 이슈로 등록합니다. 담당자와 완료 기준이 없는 Try는 등록하지 않습니다.

| Try | 담당 | 완료 기준 | Jira 이슈 |
| --- | --- | --- | --- |
| | | | |

좋은 예: "PR을 올리면 1시간 안에 리뷰어를 Slack에서 지정한다"

나쁜 예: "소통을 더 잘하자"
