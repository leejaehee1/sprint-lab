# 프로젝트 소개

## 상황

청년 지원금 AI 판정 서비스 v1.0이 운영 중입니다. 지난 품질검증 특강에서 여러 문제가 발견되어, 우리 팀이 개선 버전 v1.1을 맡았습니다.

## 목표

정해진 스프린트 안에 요구사항에 맞게 서비스 문서를 고치고 v1.1을 릴리스합니다.

## 범위

| 포함 | 제외 |
| --- | --- |
| `service/` 문서 수정 | 실제 프로그램 코드 수정 |
| 릴리스 노트 작성 | 모델 재학습 |

## 역할

인원이 적으면 겸임합니다. 교시마다 역할을 바꿔도 됩니다.

| 역할 | 하는 일 |
| --- | --- |
| PO | 우선순위와 범위 결정, 결과 승인 |
| 스크럼 마스터 | 회의 진행, 막힌 문제 해결, 기록 |
| 작성자 | 이슈를 맡아 문서 수정, PR 작성 |
| 리뷰어 | 다른 사람의 PR 검토 |

## 완료의 정의 (Definition of Done)

- 요구사항을 만족한다
- 다른 팀원 1명 이상이 PR을 승인했다
- `develop` 에 병합되었다
- Jira 이슈가 완료 상태다
- 사용자에게 보이는 변경은 `CHANGELOG.md` 에 적었다
