# 화면 문구 (v1.0)

화면 그림은 [ai-quality-bug-bash](https://github.com/leejaehee1/ai-quality-bug-bash)에서 볼 수 있습니다.

## 화면 ①: 판정 결과 (대상)

- 제목: 지원 대상입니다
- 본문: 축하합니다! 다음 달부터 지원금을 받을 수 있어요.
- 확신도: 모델 점수를 그대로 % 로 표시
- 입력한 정보: 나이, 거주 기간, 취업 여부
- 안내: 결과에 대해 궁금한 점은 청년정책과(000-0000)로 문의해 주세요.
- 버튼: 지원금 신청하기

## 화면 ②: 판정 결과 (비대상)

- 제목: 지원 대상이 아닙니다
- 본문: 아쉽지만 이번에는 지원이 어렵습니다.
- 확신도: 모델 점수를 그대로 % 로 표시
- 입력한 정보: 나이, 거주 기간, 취업 여부
  - 거주 기간 표시 형식: `{입력값}년`
- 안내: 이 결과는 AI가 판정했습니다. 최종 결정은 담당자가 확인합니다.
- 버튼: 처음으로

## 화면 ③: 입력 오류

- 나이 칸이 잘못되면 시스템 오류 메시지를 그대로 표시

```text
ValueError: invalid age: -1
```
