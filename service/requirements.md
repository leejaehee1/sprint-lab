# 요구사항 명세

서비스 문서가 이 명세와 다르면 결함입니다. 변경이 승인되면 이 문서를 먼저 고칩니다.

실습용 가상 서비스입니다.

## 판정 규칙

| ID | 요구사항 |
| --- | --- |
| R-01 | 나이가 만 19세 이상 34세 이하여야 대상이다 |
| R-02 | 해당 지역 거주 기간이 6개월 이상이어야 대상이다 |
| R-03 | 미취업 상태여야 대상이다 |
| R-04 | 세 조건을 모두 만족해야 대상이다 |
| R-05 | 나이가 숫자가 아니거나 0~120 범위 밖이면 판정하지 않고, 사용자가 이해할 수 있는 한국어 안내를 보여 준다 |

| ID | 요구사항 |
| --- | --- |
